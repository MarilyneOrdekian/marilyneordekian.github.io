# Marilyne Ordekian – academic website

Live at **https://marilyneordekian.github.io**

Built with the [academicpages](https://github.com/academicpages/academicpages.github.io) template. GitHub rebuilds the site automatically a minute or two after any file here is changed.

## How to edit (no software needed)

1. Open the file you want to change on github.com (list below).
2. Click the pencil icon ✏️ (top right of the file).
3. Make your change, then click **Commit changes…** → **Commit changes**.
4. Wait 1–2 minutes and refresh your site.

| What you want to change | File |
|---|---|
| Home page text | `_pages/about.md` |
| Name, short bio, email, sidebar links (Scholar, LinkedIn…) | `_config.yml` (the "Site Author" section) |
| Talks | `_pages/talks.md` |
| Teaching | `_pages/teaching.md` |
| Media & policy | `_pages/engagement.md` |
| CV page | `_pages/cv.md` |
| CV PDF | upload a new file named `Marilyne_Ordekian_CV.pdf` into the `files` folder (it replaces the old one) |
| Profile photo | upload a square photo named `profile.jpg` into the `images` folder (it replaces the old one) |
| Top menu | `_data/navigation.yml` |

**Tips**
- Text files use [Markdown](https://www.markdownguide.org/basic-syntax/): `**bold**`, `*italic*`, `[link text](https://...)`, and lines starting with `* ` become bullet points.
- In `_config.yml` and `_data/navigation.yml`, spacing at the start of each line matters. Copy an existing line and change only the text inside the quotes.
- If the site doesn't update, open the **Actions** tab of this repository: a red ✗ means the last change broke something, and clicking it shows which file.
